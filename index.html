About This Dashboard

Space Dashboard pulls live data from NASA, SpaceX, Open Notify / WhereTheISS.at, and the Spaceflight News API to give you a single, real-time window into what's happening above our heads. Built with plain HTML, CSS, and JavaScript — no frameworks, no build step — as a demonstration of modern front-end craft: responsive layouts, glassmorphism, accessible interactions, and resilient API handling.
